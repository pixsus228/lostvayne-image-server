LOSTVAYNE-LOQ: Image Server
Повнофункціональний сервіс для завантаження, зберігання та перегляду зображень. Проект побудований на архітектурі мікросервісів з використанням Docker та PostgreSQL.

🛠 Технології
Backend: Python (BaseHTTPServer), PostgreSQL

Frontend: HTML5, CSS3, JavaScript

Infrastructure: Docker, Docker Compose, Nginx (Reverse Proxy)

🚀 Як запустити
Для розгортання проекту виконайте команду:
docker compose up --build

Сервіс буде доступний за адресою: http://localhost

📋 Функціонал
Завантаження: Підтримка зображень (JPG, PNG) з автоматичною валідацією розміру та формату.

Управління: Перегляд списку зображень з пагінацією та функція видалення.

Безпека: Валідація файлів на стороні бекенду та коректна обробка помилок.

Бекапи: Автоматизоване створення резервних копій бази даних PostgreSQL.

📁 Структура проекту
/backend — бізнес-логіка (API, робота з БД, валідатори).

/frontend — статичний контент (HTML, CSS, JS).

/db — SQL-скрипти ініціалізації.

/backups — місце зберігання резервних копій бази даних.
